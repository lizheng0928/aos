1.3 Your First Task in Seconds

Click New Task in the left sidebar. That's it — no setup, no configuration. Just type what you need. Like talking to a coworker:

"Summarize these meeting notes and pull out the action items."
"Translate this product description into English, French, and German."
"Look at this sell-out spreadsheet and tell me which SKUs sold best and slowest in each country."

You can also use the + menu next to the input box to add files, specify a Skill, or assign a Work. The Agent automatically recognizes everything you add and uses it as context for your task.

Don't bother if you don't want to — the default model handles most daily tasks just fine.

Bottom line: You talk, AOS Work works. No tab switching. No tool setup first.

Creating a Task in 4 Steps

  • Write your task description — like talking to a coworker. State the goal, input materials, constraints, and expected output.
  • Add attachments (optional) — upload files from the + menu, or reference files from Library.
  • Send — watch the Agent's plan, tool calls, and file changes in real time.
  • Review — preview the output in the result panel, confirm it's correct, then use it.
💡 Safety tip: For your first time, work in a test folder in Library — a folder with copies of your files, not the originals. Watch what the Agent can access. Double-check your task description before working with real business data. Files can be opened locally, uploaded to the cloud, or shared — before sharing, make sure no sensitive or confidential information is exposed, and follow your company's sharing policy.

How to Write a Good Task Description

The quality of your task description directly determines the quality of the Agent's output. A good description answers six questions:

ElementWhat to answer
GoalWhat problem are you solving
InputWhich files, directories, or links to use
ActionAnalyze, organize, convert, or generate
ConstraintsWhat not to change, which standards to follow
OutputWhat to deliver, where to put it
AcceptanceWhat counts as done

Good example:

Analyze this sell-out data, calculate the sell-through rate per SKU per country, sort by sell-through ascending, and output an Excel file with six columns: SKU ID, Product Name, Country, Units Sold, Stock on Hand, Sell-Through Rate. Don't modify the original data.

Bad example:

Analyze this spreadsheet.

The difference: a good description tells the Agent what to do, how to do it, what format to use, and what counts as done. A vague description makes the Agent guess — and the output may not match what you had in mind.

Starter Tasks

Here are three beginner-friendly tasks, from easy to harder, to help you get started:

Starter A: Organize Files

Goal: Organize files in a Library folder so they're easy to find by type.Input: The "Test Files" folder in Library.Action: Identify file types, propose a categorization and rename scheme.Constraints: Don't delete or overwrite original files; keep duplicates with a sequence number.Output: First generate a file inventory table and a categorization plan.Acceptance: File count matches the actual folder, all actions are traceable. Don't move files until I confirm the plan.

Starter B: Generate Meeting Minutes (from your own typed notes — no recording software needed)

Here are my typed notes from today's meeting — turn them into structured meeting minutes. Must include: conclusions, action items, owners, deadlines, and open questions. If an owner or deadline isn't clear from the notes, write "TBD" — don't fill in guesses.Output: a meeting minutes document and an action-item table.Acceptance: every conclusion is traceable to the notes; no action item is missing owner or status.

Starter C: Word to PPT

Convert this project report Word doc into an internal presentation (10 slides max). Audience: department heads; presentation time: 8 minutes. Keep all facts and numbers from the original — don't add unverified data. Structure: background, current state, problems, solutions, plan, decisions needed.Output: a PPT file plus a slide-by-slide content summary.Acceptance: each slide has one core idea, numbers match the original, body text is readable in projection mode.
💡 Pro tip: The best way to learn AOS Work is to use it. Pick a real task you're working on — a report to write, a spreadsheet to analyze, a document to summarize — and learn by doing. It's ten times more effective than following a generic tutorial.
