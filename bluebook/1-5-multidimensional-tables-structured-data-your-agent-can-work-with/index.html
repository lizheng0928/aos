1.5 Base — Structured Data Your Agent Can Work With

Base is where you manage structured data — tables, records, and fields that the Agent can query and update.

A New Way to Organize Work

Base is designed for business workflows, not just calculations. It brings together data management, visualization, and automation in one place:

•

Multiple views, one data source — Switch between Table, Kanban, Gallery, Gantt, and Calendar views instantly. The same data looks different depending on what you need to see.

•

Automation without code — Set up rules like "When status changes to 'Done', notify the team" — no programming required.

•

Real-time collaboration — Multiple people work on the same data simultaneously, with role-based permissions (Owner/Admin/Reader).

The Real Magic: Tables Meet Conversation

Base becomes even more powerful when connected to the Agent. Instead of manually checking data, just ask:

"Check the product table and list everything with stock below 200."

The Agent queries the table, returns results, and embeds a live preview in the conversation. You can even update records directly from the chat.

Like Library, Base is embedded from the original BasilAOS system. If you haven't authorized Base yet, follow the same steps in Explore → Apps: enable Base, click Authorize, and complete the OAuth login.

Permission Management

Base comes with built-in permission management, so you can control who accesses your data and what they can do with it.

Base supports three system roles:

•

Owner — full control over the Base, including permission settings

•

Administrator — can read, edit, and manage data within the Base

•

Reader — read-only access to view data

Custom roles are coming soon, giving you even more flexibility to define exactly what each team member can do.

With permission management, you can share your Base with team members for reading or collaborative editing — keeping your data secure while enabling teamwork.
