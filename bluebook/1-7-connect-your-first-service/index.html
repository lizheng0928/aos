1.7 Connect Your First Service

Skills tell the Agent how to do things. Connectors give it a channel to the outside world.

What is a Connector?

If Skills are apps for the Agent, Connectors are the data cables to external services.

If you want the Agent to:

Read supplier emails from Outlook / Gmail

Create meetings in Google Calendar

Call your company's internal API

Those external services need a Connector.

Connectors let the Agent talk to external services — some are built on MCP (Model Context Protocol), a standard interface for AI tools; others connect directly through third-party APIs. The Explore catalog already has pre-built connectors for popular services, with more being added regularly. No coding required — just install, authorize, and start using.

Installing and Authorizing a Connector

Here's how it works:

1.

Find — browse Connectors in Explore. The Connector catalog is managed by your IT admin — Connectors need IT approval before they're available, so if one you need isn't there, request it through IT

2.

Install — click to add it to the Agent

3.

Authorize — authorize via OAuth to your Outlook or Gmail account (AOS Work never sees your password — you grant access through the provider's secure login page)

4.

Use — there are two ways to call a Connector:

￮

Natural language: just describe what you need, e.g. "check my inbox for supplier emails". The Agent automatically calls the connected Connector.

￮

Manual selection: click the "+" button in the input box, then select the Connector you want to use.

Currently, we offer two types of Connectors: AI model services (like image generation with Image 2.0 or video generation with Happy House) and external applications (like Outlook, Apify). For specific use cases, refer to Chapters 2 and 3.

A few key things:

•

Each user gets one Connection per Connector. Switching accounts? Re-authorize — it replaces the old one

•

Disconnect anytime — AOS Work cleanly revokes access

Dimension

Connector

Typical examples

Product Description Generator, Competitive Analysis Skill, Listing Optimization Skill

Model type: OpenAI Image Generation, Nano Banana Image Generator, Gemini; Service type: Outlook, Gmail, Google Calendar, Slack, Apify, Tavily Search

A typical combo: create an email assistant Skill that needs an Outlook or Gmail Connector. The Skill tells the Agent "how to process emails, what fields to extract, which table to write to." The Connector provides "read inbox, send email." Together, they complete the workflow from email to structured data.

Connectors are what turn AOS Work from a "smart assistant" into an integration platform. We'll cover specific setups and real-world examples in a dedicated chapter.
