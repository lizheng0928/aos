1.7 Connect Your First Service

Skills tell the Agent how to do things. Connectors give it a channel to the outside world.

What is a Connector?

If Skills are apps for the Agent, Connectors are the data cables to external services.

If you want the Agent to:

Read supplier emails from Outlook / Gmail
Create meetings in Google Calendar
Call your company's internal API

Those external services need a Connector.

Connectors let the Agent talk to external services — some are built on MCP (Model Context Protocol), a standard interface for AI tools; others connect directly through third-party APIs. Either way, you just install and authorize, no custom integration code needed.

Installing and Authorizing a Connector

Here's how it works:

  • Find — browse Connectors in Explore. The Connector catalog is managed by your IT admin — Connectors need IT approval before they're available, so if one you need isn't there, request it through IT
  • Install — click to add to your Agent
  • Authorize — authorize via OAuth to your Outlook or Gmail account (AOS Work never sees your password — you grant access through the provider's secure login page)
  • Bind — some Skills need a Connector to work. After authorization, the Connector is linked to the Skill that uses it
  • Use — there are two ways to call a Connector:
    1.Natural language: just describe what you need, e.g. "check my inbox for supplier emails". The Agent automatically calls the connected Connector.
    2.Manual selection: click the "+" button in the input box, then select the Connector you want to use.

A few key things:

  • Each user gets one Connection per Connector. Switching accounts? Re-authorize — it replaces the old one
  • Disconnect anytime — AOS Work cleanly revokes access

Connector vs. Skill

DimensionSkillConnector
Core purposeTells the Agent how to do a type of taskGives the Agent a channel to external services
AnalogyApp (provides a capability)Cable (connects to the outside)
ContainsInstructions, scripts, templatesAPI credentials, endpoint definitions
Typical examplesProduct Description Generator, Competitive Analysis Skill, Listing Optimization SkillModel type: OpenAI Image Generation, Nano Banana Image Generator, Gemini; Service type: Outlook, Gmail, Google Calendar, Slack, Apify, Tavily Search

A typical combo: install an "Email Follow-up" Skill that needs an Outlook or Gmail Connector. The Skill tells the Agent "how to process emails, what fields to extract, which table to write to." The Connector provides "read inbox, send email." Together, they complete the workflow from email to structured data.

Connectors are what turn AOS Work from a "smart assistant" into a true integration platform. We'll cover specific setups and real-world examples in a dedicated chapter.
