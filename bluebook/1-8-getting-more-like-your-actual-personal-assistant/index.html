1.8 Getting More Like Your Actual Personal Assistant

The more you use Workbench, the more it knows you — thanks to Memory.

Memory stores your User Profile — your role, preferences, work habits, all the "always do it this way" instructions you've given Workbench. It's not chat history. It's a living, structured, growing personal profile.

How it updates:

  • Automatic: Every day, Workbench aggregates all your tasks and updates the profile automatically
  • Manual: Type a sentence at the bottom of the Memory page — "remember to use formal tone for all client-facing content" or "forget the old brand guide" — Workbench processes it and updates immediately
  • Transparent: You can view the full profile anytime. It's read-only — you can't edit it directly, but you can always ask Workbench to change or delete something
  • Versioned: Every change creates an immutable new version. Use the calendar heatmap and side-by-side diff view to see how your profile evolves over time

Memory Follows You, Not Your Session

Key point: Memory is tied to your user account, not to a specific session or project.

What this means:

You might thinkWhat actually happens
Switch sessions, memory resetsNo — memory works across sessions
Switch projects, preferences resetNo — memory works across projects
Each session has its own profileNo — you have one profile

Specifically:

  • Cross-session: You tell Workbench in Session A "use formal tone for client content." In Session B, it still knows. The system aggregates all your tasks daily (across all sessions and tasks) and updates the same profile. Work from different sessions is all included in the daily summary — there's no "this preference only works in this session."
  • Cross-project: Projects are what you see grouped in the sidebar, but memory doesn't split by project. Preferences formed in Project A apply in Project B. You always have one user profile, and the daily summary collects data across all workspaces and projects.
  • Manual updates are global too: When you submit an update on the Memory page — "remember to use Chinese for all my reports" — it doesn't belong to any session, task, or workspace. Once written, it applies to all subsequent sessions and projects.

Bottom line: Memory and preferences are tied to you, not to whatever window you have open. No matter which session or project you're working in, Workbench knows you.

Who Can See Your Profile

Your profile is visible only to you.

  • Tenant admins can't read your profile content through the product interface
  • System audit logs record update time, source type, result, and version number — not profile content
  • Workbench only stores what you explicitly provide or what can be objectively identified from your work behavior — no sensitive data, no passwords, no guessing

The result: the more you use it, the less you need to repeat yourself. "I'm in marketing, I need English and Italian, I prefer concise bullet points" — Workbench just knows.

At this point, it stops feeling like a tool and starts feeling like a real assistant.
