1.8 Getting More Like Your Actual Personal Assistant

Now that you've connected external tools, let's see how AOS Work learns about you — the other key to making it work better over time.

The more you use AOS Work, the more it knows you — thanks to Memory.

Memory stores your User Profile — your role, preferences, work habits, all the "always do it this way" instructions you've given AOS Work. It's not chat history. It's a living, structured, growing personal profile.

How it updates:

•

Automatic: Every day, AOS Work aggregates all your tasks and updates the profile automatically

•

Manual: Type a sentence at the bottom of the Memory page — "remember to use formal tone for all client-facing content" or "forget the old brand guide" — AOS Work processes it and updates immediately

•

Transparent: You can view the full profile anytime. It's read-only — you can't edit it directly, but you can always ask AOS Work to change or delete something

•

Versioned: Every change creates an immutable new version. Use the calendar heatmap and side-by-side diff view to see how your profile evolves over time

Memory Follows You

Key point: Memory is tied to your user account, not to a specific conversation or project.

What this means:

You might think

What actually happens

Switch sessions, memory resets

No — memory works across sessions

Switch projects, preferences reset

No — memory works across projects

Each session has its own profile

No — you have one profile

Specifically:

•

Cross-conversation: You tell AOS Work in conversation A "use formal tone for client content." In conversation B, it still knows. The system aggregates all your tasks daily (across all sessions and tasks) and updates the same profile. Work from different sessions is all included in the daily summary — there's no "this preference only works in this session."

•

Cross-project: Projects (explained in Chapter 4) are what you see grouped in the sidebar, but memory doesn't split by project. Preferences formed in Workspace A apply in Workspace B. You always have one user profile, and the daily summary collects data across all workspaces and projects.

•

Manual updates work across all sessions and projects too: When you submit an update on the Memory page — "remember to use Italian for all my reports" — it doesn't belong to any session, task, or workspace. Once written, it applies to all subsequent sessions and projects.

In summary: Your preferences follow you across all sessions and projects.

Who Can See Your Profile

Your profile is visible only to you.

•

Tenant admins can't read your profile content through the product interface

•

System audit logs record update time, source type, result, and version number — not profile content

•

AOS Work only stores what you explicitly provide or what can be objectively identified from your work behavior — no sensitive data, no passwords, no guessing

The more you use it, the less you need to repeat yourself — your Agent learns your preferences and becomes a real assistant.
