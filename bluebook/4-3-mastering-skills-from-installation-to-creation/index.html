4.3 Mastering Skills: From Installation to Creation

Finding and Installing Skills in Workbench

Open Explore in the left sidebar — it's like an app store, but instead of apps, it installs AI capabilities.

You can:

  • Browse recommendations — see what's available, filter by category
  • Search — describe what you need in natural language, Workbench matches the Skill
  • Install — click Add, confirm, done. The Skill loads into the Agent's context automatically
  • Use — type "/" in the conversation to see your installed Skills, select the one you need

Solving a Task with a Skill

Say you have a sales data table and want the Agent to analyze trends and anomalies. Find the "Data Analysis" Skill in Explore, install it, then say "analyze this table and rank SKUs by sell-through rate, flagging the 10 slowest sellers."

Workbench loads the Data Analysis Skill's methodology — e.g. "first do a data overview (row count, fields, data types)" → "calculate key metric distributions" → "flag anomalies with cause hypotheses" → "output a structured analysis report" — then executes the analysis using that methodology.

You get a structured analysis report with a data overview, anomaly SKU list, trend charts, and action recommendations. You didn't write a single prompt describing the analysis steps. The Skill has built-in execution logic. You just provide the data input and review the output.

From Using Skills to Writing Skills

Using other people's Skills is the starting point. The real value comes from writing your own Skills.

You don't need to write Markdown from scratch. Workbench's SkillHub has a built-in Skill called WorkSkill Maker — it's a Skill that creates Skills. Tell it in natural language what you want to do, and it generates the SKILL.md.

Creating Your First Skill with WorkSkill Maker

The flow is simple:

  • Open the conversation, invoke WorkSkill Maker In the Workbench conversation, say: "I want to create a Skill for batch-renaming product images." WorkSkill Maker guides you through clarifying the requirements.
  • Describe what you want in natural language WorkSkill Maker asks a few questions: what problem does this Skill solve? What's the input? What's the output? What rules must be followed? You answer like you're talking to a coworker. It formats everything into a SKILL.md.
  • Review the generated SKILL.md WorkSkill Maker generates a complete Skill file. Check these key parts:
Check itemWhat to look for
nameShort and clear
descriptionThe most important field — this determines when the Skill auto-activates. Include keywords the user might say
Step instructionsIs the execution flow complete? Did it miss any of your experience points?
NotesDid it include the "gotchas" you told the AI about?
  • Understand the activation mechanism The description field determines when the Skill activates. Example: if you're creating a "batch-rename product images" Skill, the description should be something like: "For batch-renaming product images in Library, following the category_SKU_color_date naming convention. Activates when the user mentions image renaming, file name normalization, or product image rename." This way, when you say "rename these product images," the Agent auto-loads this Skill.
  • Test and iterate Run the Skill once and see if the result is correct. If not, modify the SKILL.md and run again.

Your First Skill Won't Be Perfect

This is important: your first version of a Skill will almost certainly be imperfect. In real use, you'll find:

  • Some steps the Agent misunderstood — need to rephrase
  • Some experience you forgot to write in — the Agent missed a step
  • Some rules need constraints — "don't modify original files" or "confirm with me before executing"
  • The description is too narrow — certain scenarios don't activate it; or too broad — it activates when it shouldn't

This is normal. The value of a Skill is in continuous improvement. In the conversation, you can tell the Agent:

"Remember what we discussed today. This Skill's rules need updating: 1. Keep the original file name as a note when renaming; 2. Use C prefix for color codes, not D."

Or even more directly:

"What can you learn from the conversation above? Remember and optimize this Skill."

The Agent incorporates your feedback into the SKILL.md. Next time, it runs with the updated rules. The more you use it, the more accurate it gets — that's the evolution from "personal prompt" to "organizational capability asset."
