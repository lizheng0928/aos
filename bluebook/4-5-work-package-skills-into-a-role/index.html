4.5 Work: Package Skills Into a Role

You've installed Skills and they work well. But every time you start a task, you still have to think "which Skills should I use this time?"

Work solves that. Work is a bundle of Skills, packaged for a specific role or a complete job.

Simply put: Skill is an "everyday tool." Work is a "job tool kit."

For everyday general tasks, Skills are enough. But when you need to complete a full job — like generating a weekly Amazon competitor report or launching a new listing in three languages — you need a coordinated set of capabilities. That's when Work is much more efficient than picking Skills one by one.

How to Use Work

1.

Find and install: Open Explore → Work tab → click Add

2.

Use in a task: Click + menu next to input box → select the Work → all Skills load together

3.

Direct the Agent: Tell it what to do — the Agent won't auto-call Skills

Recommended approach: Create different sessions within a Workspace for different tasks. Earlier sessions write data to the Base. Later sessions read from the Base to aggregate.

Real Example: Amazon Operations Work

Amazon operations is fragmented but interconnected: monitoring competitors, reading reviews, optimizing listings, checking ads, writing reports. Each task needs a different capability, but they're one complete operational chain.

Packaged as "Amazon Operations Work", it includes 6 Skills: competitor monitoring, review analysis, listing optimization, keyword research, ad data analysis, and weekly report. Pick one Work, and all Skills load together.

Scenario Demo: A Complete Operations Chain

Sub-scenario A: Daily competitor + review check

Today's Amazon operations check: - My listings: B0DXXXXXX (Women's knit cardigan), B0DYYYYYY (Men's jacket) - Competitors: 3 ASINs in the same category - Check: 1. Did any competitor change price overnight? What's the price gap with mine? 2. Did any competitor change their title/bullet points? List changes if any. 3. How many new reviews for me and competitors? Sentiment (positive/negative/neutral)? 4. What are the common issues in negative reviews? (size/fabric/logistics/other) - Output: Write to the "Daily Check" view in your Base, one row per ASIN

The Agent calls Competitor Monitoring Skill → Review Analysis Skill → writes results to the table. A few minutes later, you have a check table in your Base, all clear at a glance.

Sub-scenario B: New listing launch

New listing generation: - Product: Women's cashmere scarf, ASIN pending - Target markets: US + EU (English/German/Italian) - Output: 1. Title (≤200 characters, with core keywords) 2. Bullet points (5, ≤500 characters each, features + specs) 3. Product description (≤2000 characters) 4. Backend search terms (≤250 characters) 5. English → German → Italian versions - Constraint: Keywords from real Keyword Research Skill data

The Agent calls Keyword Research Skill → Listing Optimization Skill → Multi-language copy generation Skill. You get a complete three-language listing set, ready to copy and paste into Amazon Seller Central.

Sub-scenario C: Friday weekly report

Generate this week's Amazon operations weekly report: - Time range: Last Monday to this Sunday - Sections: 1. Sales overview: total revenue, units ordered, return rate (vs. last week) 2. Review dynamics: new review count, average star rating, Top 3 negative review reasons 3. Competitor changes: price adjustments, listing modifications, new launches 4. Ad performance: total spend, ACoS, conversion rate, Top 5 spend keywords 5. Next week focus: 3 action items based on the above data - Data sources: "Daily Check" view + ad reports + inventory table in your Base

The Agent reads from your Base — the data written by the previous sessions — and assembles a standardized report using the Operations Weekly Report Skill. The prerequisite: each previous session wrote its data to the Base.

💡 In short: The Amazon ops specialist's fragmented tasks — monitoring competitors, writing listings, producing weekly reports — no longer need five tools and five switches. Pick one Work, and all Skills load together.
