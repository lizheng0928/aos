2.1 Email Management & Structured Follow-ups

You get 10+ supplier emails a day, each with a Tech Pack PDF, product images, or a quote. Information is scattered across your inbox — untrackable, unqueryable. A general-purpose AI assistant can help you draft replies, but it isn't connected to your inbox or your tables — you'd still move everything in and out by hand. AOS Work turns key information from emails directly into structured records in a Base.

What you can do:

•

Read Outlook / Gmail inbox emails, extract key info (supplier/order/amount/delivery date) and write it to a Base

•

Auto-extract email attachments (images/PDFs/Excel files), save them to Library with tags

•

Draft multi-language email replies, confirm, then send — all from AOS Work

Steps:

1.

In Explore, install the Outlook or Gmail Connector and authorize it (Connectors are enabled and approved by your IT admin — ask IT if it isn't listed)

2.

Tell the Agent which emails to process, what fields to extract, and which table to write to

3.

The Agent reads the emails, extracts the data, and creates structured records

4.

Attachments are saved to Library automatically, linked to the table records

5.

Need to reply? State your key points and language — the Agent drafts the email

6.

Confirm, send — all inside AOS Work

Tip: The Agent drafts the email for you — review the content carefully before sending. You stay in control of what goes out.

Example prompt:

Read the last 10 supplier emails from my inbox. Extract the following and write to a Base: supplier, email date, order number, amount, key request, attachment list. Save any images from attachments to Library, named "supplier_order_date" and tagged "supplier email."

Expected results:

•

10 emails → one structured Base

•

Attached images saved to Library, searchable by supplier/order

•

Later, you can just ask the Agent "What did Hartmann send this week?" and get the answer from the table

Sub-scenario 1-A: Customer Service — Batch Complaint Email Follow-ups

You're a customer service lead. Your team gets 20+ complaint emails a day, each with attached photos (quality issue shots). Complaints scatter across individual inboxes — trends stay invisible, progress is hard to track.

With AOS Work, the Agent batch-reads complaint emails, auto-classifies and rates severity, files images to Library, and writes everything to a trackable Base.

Read the last 20 complaint emails from my inbox. Extract and write to a Base: customer name, order number, complaint type (quality/logistics/sizing/other), issue description, severity (P1-P3), attached images, handling status, assignee. Requirements: 1. Auto-classify complaint type by analyzing email body keywords; 2. Auto-rate severity (P1 = batch impact/escalation, P2 = single-item issue, P3 = general inquiry); 3. Auto-save attached images to Library, named "customer_order_number."

Expected results:

•

20 scattered emails → one structured Base within minutes

•

Complaint images auto-filed in Library, searchable by customer/order

•

Supervisors can spot trends directly from the table: "Quality complaints are up this month"

•

Downstream: the Agent can reference "Hartmann's complaint photos" in later conversations — less time digging through emails

Sub-scenario 1-B: Project Manager (see Chapter 4) — Supplier Emails + Attachments → Project Tracking Table

You're a project manager. 10+ supplier emails a day, each with a Tech Pack PDF, product images, or sample photos. Information lives in your inbox. When you meet with the team, you're digging through emails.

With AOS Work, the Agent reads recent supplier emails, auto-extracts key info and attachments, and writes to a project tracking table grouped by supplier.

Read supplier emails from my inbox (last 7 days). Extract and write to a project tracking Base: supplier, project/style number, email subject, email date, key content summary, attachment list, attachment type, sampling stage, action needed, deadline. Requirements: 1. Auto-classify attachments: Tech Pack PDFs → extract key parameters (fabric/size/color) into the table; 2. Product images → save to Library, named "supplier_style_date"; 3. Highlight the "action needed" column so it's easy to review in meetings.

Expected results:

•

Scattered supplier emails → one project tracking table grouped by supplier

•

Tech Pack parameters are no longer buried in PDFs — they're queryable in the table

•

Sample photos auto-filed in Library, linked to the supplier row

•

Project manager asks AOS Work: "What did Hartmann send this week? How's the progress?" → the Agent answers from the table

•

Downstream: Friday's weekly report auto-pulls table data to generate a progress update.

Compliance note: Under GDPR, emails contain personal data (sender name, contact details, content). Ensure:

1) You have a lawful basis for processing (e.g., legitimate interest for business communications); 2) Extracted data is used only for business follow-up; 3) Delete data that is no longer needed.
