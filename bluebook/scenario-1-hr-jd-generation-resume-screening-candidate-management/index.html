Compliance note: When generating JDs for multiple roles at once, start with one role, confirm quality, then batch the rest. Batch results are written to the same table.

Sub-scenario B: Resume Screening & Matching — 200 Resumes, Ranked in Minutes

Pain Point

"200 resumes for one role. If I spend 5 minutes on each, that's 16 hours of screening. And I still miss great candidates."

Steps

1.

Upload resumes. Upload a batch of resumes (PDF/Word) to the AOS Work conversation.

2.

AI auto-parses. The AI reads each resume and extracts key info:

Field

Description

Name

Full name

Experience

Total years of work

Skills

Industry tools, professional skills, software

Languages

Languages and proficiency

Last employer

Most recent company

Current role

Most recent job title

3.

Input job requirements, AI scores the match. Tell the AI which role you're hiring for. It calculates a match score (0–100) for each candidate and ranks them.

4.

Results written to the Base. The match ranking table goes into the table. Hiring managers can view, filter, and sort. Original resume files (PDF/Word) can also be linked to the corresponding records.

5.

Natural language follow-up queries. You can filter candidates directly with natural language:

List all candidates with 3+ years luxury experience, Italian B2 or above, currently in Milan. Sort by match score descending.

Task Instruction

Parse the following resumes, extract key info (name, experience years, skills, languages, education, current role). Match against the following job requirements: - Role: Senior Merchandiser - Requirements: 5+ years fashion industry, Italian native or C1+, English B2+, proficient in Excel and data analysis tools Generate a match ranking table (0–100 points), write to the Base, including: Name, Experience years, Current role, Last employer, Skills, Languages, Match score, Rank. Link original resume files to the corresponding records.

Expected Results

•

All resumes auto-parsed, match scores clear at a glance

•

Base supports filtering and sorting — hiring managers can view directly

•

You can query specific candidates using natural language

Advanced: Auto-update Interview Feedback

After the interview, type your evaluation directly in AOS Work:

Candidate Marco Rossi interview feedback: Strong industry experience, deep understanding of merchandising, fluent English, Italian needs improvement. Result: proceeding to second round. Recommend scheduling a technical interview with the team lead.

The AI auto-updates the feedback and result in the Base.

Advanced: Auto-reminder for Candidates Without Follow-up

Set up a scheduled reminder: candidates not followed up within 7 days are auto-flagged:

Set up reminder: In the Base, candidates with status "Pending" and no update for 7+ days should be auto-flagged in red for the recruiter.

Compliance note: Under GDPR and EU Anti-Discrimination Directive (2000/78/EC), personal data in resumes is sensitive. Ensure: 1) Only collect information directly relevant to the role; 2) Do not use age, gender, race, religion, or marital status as scoring criteria; 3) Retain candidate data only as long as needed for the hiring purpose (recommend deleting un-hired candidate data within 6 months).
