Chapter 3 · Role-Specific Scenarios

Scenario 4 · Designers: AI Image Generation & Fabric Recoloring

A designer's work is about "seeing" and "drawing" — finding inspiration, sketching, color-matching, building lookbooks. Every task takes time and aesthetic judgment. This chapter shows you how to hand the repetitive visual work to the Agent: turn model photos into flat lays, recolor flat sketches, and let designers spend their time on creative decisions.

The Designer Workflow

Whether you're a fashion designer or a visual designer, the daily flow is the same:

StepTraditional approachPain point
1. Inspiration gatheringBrowse Pinterest, Instagram — manually screenshotHigh volume, hard to categorize, not directly reusable
2. SketchingHand-drawn or CTD software, one by oneEvery colorway needs a separate drawing
3. Color confirmationSample → photo → compare → approve2-3 week cycle, back-and-forth communication
4. Flat lays / LookbooksStudio shoot or 3D renderTight schedule, high cost, too many SKUs

With Workbench, steps 2-4 can be handled by the image-generator Skill. Output goes directly to Library, linked to the Base.

Sub-scenario A: Model Photo to Flat Lay — One Image, Direct Output

Pain Point

Hundreds of SKUs each season need flat lay photos. The photography schedule is tight, and outdoor shoots are expensive. Studio model photos already exist, but lookbooks and e-commerce product pages need flat lays. Reshooting? Not enough time or budget.

What Makes This Different

Generic AI image tools (Midjourney / DALL-E) don't lock garment attributes — the result "looks like but isn't the same garment." Workbench's image-generator, in edit mode, locks the original garment's attributes: no new design, same garment, flat presentation.

Steps

  • Find a studio model photo or product shot in Library
  • In the conversation, invoke image-generator and select "Model to Flat Lay" mode
  • The Agent receives the original image, locks garment attributes (style, fabric, details), and generates the flat lay
  • The output PNG is saved directly to Library with tags (category/season/SKU)
  • Link the image to the corresponding record in the Base

Task Instruction

Convert this model photo from Library into a flat lay image. Output in PNG format. Save to Library folder "2026SS", tag with: category=outerwear, season=2026SS.

Expected Results

  • A flat lay image with the original garment's attributes locked (PNG format)
  • Saved to the specified Library folder with tags
  • Linkable to the corresponding SKU record in the table

Advanced: Garment to Flat Sketch Mode

The same photo can also use "Garment to Flat Sketch" mode, generating a technical sketch suitable for Tech Packs. The sketch can then be used for recoloring.

Sub-scenario B: Fabric Recolor — Input PLM Color Code, Change the Sketch

Pain Point

One style comes in 5-8 colorways. Each colorway needs sampling, photography, retouching — a 2-3 week cycle. Clients and managers review color cards back and forth without seeing the actual garment. By the time colors are confirmed, the market window has almost closed.

How This Is Different from Scenario A

Scenario A changes the presentation format (model photo → flat lay). Scenario B changes the color (same garment, different colorways). Both lock garment attributes, but Scenario B only replaces the fabric color, with special handling for denim.

Steps

  • Find a colored flat sketch (Tech Pack flat sketch) in Library or the table
  • Get the target color code from the PLM system or table
  • In the conversation, invoke image-generator, select "Fabric Recolor" mode, input the original image + color reference
  • The Agent locks the garment style, replaces only the fabric color, and applies special denim rules automatically
  • The recolored image is saved to Library and linked to the SKU's table record

Task Instruction

Recolor the flat sketch of this jacket from Library using PLM color code CL-0274. Save the output to Library and link it to the record SKU-2026-FW031 in the Base.

Expected Results

  • A recolored flat sketch — garment style unchanged, color replaced by PLM code
  • Denim fabric with special handling rules applied automatically
  • Saved to Library, linked to the SKU record
  • Ready for internal approval and client confirmation — shorter pre-sampling communication cycle

Summary

A designer's core value is aesthetic judgment and creative decisions, not repeatedly drawing colorways or shooting flat lays. Hand the repetitive visual work to image-generator. Designers spend their time on the part that needs a human.
