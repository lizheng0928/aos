Scenario 5: Fashion Industry News & Inspiration Search

Generic search engines give you one answer at a time, but the source isn't guaranteed, timeliness isn't assured, and there's no scheduled tracking. Workbench's fashion industry search uses a curated source list (WWD, Vogue Business, Drapers, Sourcing Journal), routes to a dedicated search Skill, and writes structured results to a Base.

Skills involved:web-search (searches the web for the latest information, gives you summaries and source links — saves you from opening each page yourself); fashion-inspiration-skill (advanced: uses Apify to scrape Instagram, Pinterest, or any website for fashion images on a schedule — AI auto-classifies by style, color, fabric, category — delivers a shareable inspiration board HTML every morning); single-html-generator (turns search results into an HTML brief)

Steps:

  • Tell the Agent what topic to search and which sources to use
  • The Agent searches from the curated source list and extracts key information
  • Results are structured and written to a Base by topic/date/source
  • Need scheduled tracking? Set it as a recurring task (e.g. auto-run every morning)

Example prompt:

Search the past week's industry news about "sustainable fabrics." Limit sources to WWD, Vogue Business, Drapers. For each result, extract: title, source, date, key insight, relevance to us (high/medium/low). Write to an "Industry News" Base.

Advanced: Scheduled Inspiration Scraping

Designers spend 1-2 hours a day browsing Instagram and Pinterest for inspiration. Use Apify to scrape specified brands/styles on a schedule. By the time designers get to the office, the inspiration board is ready.

Set up a designer inspiration scraper: brands = Ralph Lauren, Diesel, Guess; channels = Instagram and Pinterest; schedule = daily at 7:00 AM; focus on: new launches, runway looks, street style, color trends. Save results to the Library inspiration folder.

Expected results:

  • Structured news written to a Base: title, source, date, key insight, relevance
  • Sources limited to a curated list — results are trustworthy and traceable
  • Once set as a recurring task, it runs daily — no manual trigger needed
  • Inspiration images auto-saved to Library — designers see them when they arrive
